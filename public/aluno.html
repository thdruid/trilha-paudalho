Biblioteca de aprendizagem

Entenda antes de resolver

Use estes exemplos curtos para descobrir como cada comando funciona. A linguagem aqui é pseudocódigo: simples de ler, sem exigir decorar uma linguagem profissional.

💡
🧭Sequência6º ano · uma ação por vez

Um algoritmo é uma lista de passos na ordem certa.

andar()
virar(direita)
andar()
🔁Repetição6º–7º ano · evite repetir trabalho

Quando uma ação se repete, um laço deixa o programa menor.

repetir 3 vezes {
  andar()
}
🚦Decisão7º ano · o programa observa

Use uma condição para escolher o que fazer em cada situação.

se (tem_obstaculo) {
  desviar()
}
📦Variáveis8º ano · guardar informações

Uma variável é uma caixa com nome para guardar um valor que pode mudar.

pontos = 0
pontos = pontos + 10
🧩Funções8º–9º ano · reaproveitar soluções

Funções agrupam passos que você usa mais de uma vez.

função saudacao(nome) {
  mostrar(nome)
}
🔎Depuração9º ano · investigar erros

Depurar é testar, observar o resultado e corrigir um passo por vez.

contador = 0
enquanto (contador < 5) {
  contador = contador + 1
}
Estúdio de projetos

Transforme uma ideia em solução

Use programação para observar um problema da escola ou do bairro, imaginar uma solução e planejar os primeiros passos.

🚀

Salve como rascunho e envie ao professor quando estiver pronto.

Roteiro do criador

  1. Observe um problema real.
  2. Escolha quem será ajudado.
  3. Divida a solução em passos.
  4. Teste, peça opinião e melhore.

Quando o projeto estiver pronto para a turma, ele pode virar uma atividade acompanhada pelo professor.
